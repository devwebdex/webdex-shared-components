# {{name}}

Projeto gerado pelo `@devwebdex/create` (WEbdEX).

## Requisitos

- Node ≥ 22 e pnpm 10
- Token do GitHub com `read:packages` no seu `~/.npmrc`, para instalar os pacotes `@devwebdex/*`:
  ```
  //npm.pkg.github.com/:_authToken=<seu-token>
  ```

## Começando

```bash
pnpm install
```

O gerador já criou cada `.env` a partir do `.env.example` com valores de desenvolvimento local. Em um clone novo, copie-os manualmente.
